# Support

AI Token Checker is a public preview. Questions, reproducible bugs, and feature
requests are welcome in [GitHub Issues](https://github.com/BoozJames/ai-token-usage-checker/issues).

Before opening an issue:

1. Update VS Code and the relevant provider CLI or official extension.
2. Run **AI Token Checker: Refresh**.
3. Check the provider requirements and known limitations in the README and
   `ACCURACY.md`.
4. Include the extension version, operating system, provider, displayed state,
   and safe reproduction steps.

Never include access tokens, credentials, account identifiers, prompts,
transcripts, proprietary source code, raw provider responses, or local file
paths in an issue or screenshot.

Report security vulnerabilities through GitHub's private vulnerability
reporting feature as described in `SECURITY.md`, not through a public issue.

Only the latest published preview is supported before the first stable release.
